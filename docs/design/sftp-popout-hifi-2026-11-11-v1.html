主流参照 · 取什么、舍什么

弹窗形态不是 dock 面板放大，而是按独立文件管理器的标准重排工具栏与导航；视觉语言仍全部走 MTerm 主题槽位。

工具栏补导航组← WinSCP / ForkLift

dock 态只有路径框+刷新；独立窗补齐「后退 / 前进 / 上级 / 主目录」历史导航与可编辑路径框（回车前往、错误红边提示）。这是弹窗最大收益：脱离终端后仍要能独立漫游。

传输队列常驻入口← WinSCP / FileZilla

下载/上传立即生成队列任务（进度 / 速度 / 暂停 / 取消），工具栏「队列」钮带计数徽章，有新任务自动展开抽屉。dock 态高度太挤放不下，弹窗是它正确的家。

标题栏主机身份← Transmit / Termius

标题写「SFTP · deploy@web-01」+ 协议徽章 + 连接状态点。多标签页开多台主机时，弹窗任务栏项一眼可辨；置顶钮配合「边看文件边跑命令」。

保留实机既有契约= ui/sftp_panel.slint

文件/隧道分段、28px 行、26px 右键菜单、多选批量行、列显示开关、复制到标签页（transfer-targets）全部原样继承——弹窗只是换宿主，不发明新交互。

交互契约 · 稿内可点验清单

全部可点；「落地映射」列为抽 SftpPanel 成顶层组件时的 Rust/Slint 接线点。

窗口壳（新增）

  • 拖标题栏移动 / 右下 grip 缩放 / 最大化还原
  • 置顶切换（高亮态）—— 落地映射 always_on_top
  • ✕ / 停靠钮 / 最小化 → 都回停靠靠（dock 面板恢复）
  • 弹出⇄停靠往返动效 320ms

导航（继承 + 补齐）

  • 树展开收起 / 点节点前往；拖分隔条调树宽
  • 后退/前进/上级/主目录 + 路径框回车跳转
  • 双击目录进入、刷新当前目录
  • 不存在路径 → 输入框红边「路径不存在」

列表（继承实机）

  • 列头点名称/类型/大小/时间三态排序
  • 勾选多选 + 全选（半选态）；批量行出现
  • 右键行/空白两套菜单（禁用项置灰）
  • 重命名行内编辑（Enter 提交 / Esc 取消 / 重名校验）

传输与隧道
