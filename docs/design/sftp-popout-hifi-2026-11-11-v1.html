v2 优化清单 · 参照主流取什么

参照 WinSCP（右键/权限/队列契约）、Transmit / Cyberduck（简洁浏览器 + 拖拽移动）、Termius（现代过滤与隐藏文件开关）、Windows Explorer（右键菜单惯例与快捷键）。

右键六场景← WinSCP / Explorer

行与空白之外补齐：树节点（新建/刷新/复制路径/在终端打开）、列头（列显示）、路径框（复制/粘贴前往）、队列任务（暂停/取消/重试）、标题栏（置顶/停靠/最小化）。菜单样式 26px 行沿用实机 SftpMenuItem。

文件管理标准操作← Explorer / ForkLift

复制（Ctrl+C）→ 粘贴（Ctrl+V）生成副本；Del 删除、F2 重命名、Ctrl+A 全选、Ctrl+F 过滤；拖文件行到树目录 = 移动（落点高亮）。

可见性三件套← Termius / Cyberduck

隐藏文件开关（工具栏 eye，状态栏计数）；搜索过滤条（Ctrl+F 展开实时过滤 + 命中计数）；批量操作行（勾选 > 0 时工具栏出现下载/复制到标签页/删除）——实机 selected-count 契约。

质感细节← Transmit

导航加载条（列表顶 2px accent 流条）；排序列头 accent-tonal 高亮 + 常显方向箭头；文件类型四档着色（脚本琥珀/配置 accent/文档次级/隐藏弱化）；自绘 tooltip 悬浮钮上方（对齐实机 SftpTooltip 负 y）。
