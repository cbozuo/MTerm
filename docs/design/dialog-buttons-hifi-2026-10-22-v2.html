灰按钮的问题不在参数，在没有层级

上一版我只统一了尺寸和圆角，这不够——你问的两点都成立： 「取消」和「随机」长得一模一样，可它们一个是退出、一个是功能操作； 而这套灰按钮本身的边框对比度只有 1.42:1，在深色面板上基本看不见轮廓， 更糟的是禁用态和常态只差 0.62 档，用户分不清哪个能点。

所以这一版改成按语义分四层：主操作实心、功能操作浅填充、退出类完全无底、破坏类红描边。 三层按钮从此各有各的形状。交互补齐 悬停 / 按下 / 键盘焦点 / 禁用 / 异步进行中 / 防重复点击 六项—— 全部只用 Slint 能写的属性，末尾附实现代码。

「取消」「随机」要不要重新设计？ 要。它们现在共用一套灰描边；分层后「取消」变成无底文字按钮（只是离开），「随机」变成浅填充按钮（会改状态），视觉上不再同级。
交互要不要重新设计？ 要。现状只有 hover 和 pressed，没有键盘焦点、没有异步进行中、没有防重复点击。「测试连接」是唯一会连服务器的按钮，点完必须给反馈。

03

六项交互，逐项给实现

每项都标注 Slint 的表达方式。凡是它做不到的（比如按下/松开分别计时长），这里直说，不画一个实现不了的效果。

① 悬停 / 按下同一个 animate，100ms

常态

按下
事件变化Slint

按下背景再深一档（Secondary 压回 #262B33）TouchArea.pressed
过渡统一 100ms 线性animate background { duration: 100ms; }

受限于 Slint：animate 对同一属性只有一条时长，没法「按下 60ms、松开 180ms」。 所以统一 100ms，靠颜色差（不是时长差）表达按下感。
上图并排看不出差异是正常的——三档色差 1.23 / 1.36 / 1.67，远小于文字对比度差； 真实使用里由过渡动画放大感知。要看阶梯关系请翻到本页末尾的「底色阶梯」。

④ 异步进行中「测试连接」是唯一会连服务器的按钮

05

落成代码

一个组件覆盖四层 + 六项交互。属性全部在 Slint 能力范围内：布局用 HorizontalLayout， 状态用 TouchArea.has-hover / pressed 与 FocusScope.has-focus， 过渡用 animate，异步用 Timer。 

// widgets.slint —— 弹框页脚按钮的唯一实现（替换五处手写 + 两个旧组件）
export enum FootTier { primary, secondary, ghost, danger }

export component FootButton inherits Rectangle {
    in property <string> text;
    in property <string> glyph: "";
    in property FootTier tier: FootTier.secondary;
    in property <bool> disabled: false;
    in property <bool> busy: false;        // 异步进行中（测试连接）
    in property <int> busy-state: 0;       // 0 进行中 / 1 成功 / 2 失败
    in property <length> btn-width: 0px;   // 0 = 按内容
    callback clicked();

    property <bool> inert: disabled || busy;
    property <bool> hot: ta.has-hover && !inert;
    property <int> dots: 0;

    // 异步时文字后缀轮点：. → .. → ... （Timer 驱动，不依赖旋转动画）
    Timer {
        interval: 400ms;
        running: root.busy && root.busy-state == 0;
        triggered => { root.dots = (root.dots + 1) % 4; }
    }

    height: 34px;
    min-width: btn-width > 0px ? btn-width : 76px;
    border-radius: 8px;
    border-width: tier == FootTier.danger ? 1px : 0px;
    border-color: hot ? Theme.danger : Theme.danger-strong;

    background: inert ? (tier == FootTier.ghost ? transparent : Theme.bg-elevated)
        : tier == FootTier.primary
            ? (ta.pressed ? Theme.accent-pressed
               : hot       ? Theme.accent-hover
                           : Theme.accent)
        : tier == FootTier.secondary
            ? (ta.pressed ? Theme.bg-active
               : hot       ? Theme.foot-secondary-hover   // #3A4049
                           : Theme.foot-secondary)        // #2E323C
        : tier == FootTier.ghost
            ? (ta.pressed ? Theme.foot-secondary         // #2E323C
               : hot       ? Theme.foot-ghost-hover       // #2A2E36
                           : transparent)
        : (hot ? Theme.danger.with-alpha(0.10) : transparent);
    animate background, border-color { duration: 100ms; }

    // 焦点：FocusScope 负责键盘，环画在外层兄弟节点（见 FootButtonFocusRing）
    fs := FocusScope {
        key-pressed(e) => {
            if !root.inert && (e.text == "\n" || e.text == " ") {
                root.clicked();
                return accept;
            }
            return reject;
        }
    }
    out property <bool> focused: fs.has-focus;

    HorizontalLayout {
        padding-left: glyph == "" ? 18px : 14px;
        padding-right: 18px;
        spacing: 7px;
        if glyph != "" || busy : Icon {
            glyph: root.busy && root.busy-state == 0 ? "clock"
                 : root.busy-state == 1 ? "check"
                 : root.busy-state == 2 ? "alert"
                 : root.glyph;
            size: 15px;
            tint: root.inert ? Theme.text-muted
                : root.busy-state == 1 ? Theme.ok
                : root.busy-state == 2 ? Theme.danger-strong
                : root.tier == FootTier.primary ? Theme.accent-on
                : root.tier == FootTier.danger ? Theme.danger-strong
                : Theme.text-primary;
        }
        Text {
            text: root.busy
                ? (root.busy-state == 1 ? @tr("Connected")
                 : root.busy-state == 2 ? @tr("Failed")
                 : @tr("Connecting") + (root.dots == 1 ? "."
                    : root.dots == 2 ? ".." : "..."))
                : root.text;
            color: root.inert ? Theme.text-muted
                : root.tier == FootTier.primary ? Theme.accent-on
                : root.tier == FootTier.danger ? Theme.danger-strong
                : root.tier == FootTier.secondary ? Theme.text-primary
                : (root.hot ? Theme.text-primary : Theme.text-secondary);
            font-size: Theme.fs-md;      // 13px
            font-weight: root.tier == FootTier.primary ? Theme.fw-strong : Theme.fw-regular;
            vertical-alignment: center;
        }
    }

    ta := TouchArea {
        enabled: !root.inert;
        mouse-cursor: root.inert ? default : pointer;
        clicked => { fs.focus(); root.clicked(); }
    }
}

// 焦点环必须单独一层：画在按钮内部会被 clip 裁掉
export component FootFocusRing inherits Rectangle {
    in property <bool> on: false;
    x: -3px; y: -3px;
    width: parent.width + 6px;
    height: parent.height + 6px;
    border-radius: 10px;          // 按钮 8 + 2
    background: transparent;
    border-width: 3px;
    border-color: Theme.accent.with-alpha(0.22);
    visible: root.on;
}

// theme.slint —— 新增 4 个 token
out property <color> accent-on: #06231F;          // accent 上的文字（7.87:1）
out property <color> foot-secondary: #2E323C;     // 次按钮常态底（1.36:1）
out property <color> foot-secondary-hover: #3A4049; // 次按钮悬停（1.67:1）
out property <color> foot-ghost-hover: #2A2E36;     // Ghost 悬停（1.29:1）

验收可测量，不靠主观

  • 五处页脚按钮同高 34px、页脚总高 58px，用离屏像素探针断言（参照 tests/sidebar_edge_line.rs）。

  • 亮色主题另算：accent-on 要取白，foot-secondary 取亮色系的次级面。

局限：Slint 的 animate 对同一属性只能设一条时长，所以没有「按下更快、松开更慢」；焦点环需要外层兄弟节点，不能画在按钮自身。
