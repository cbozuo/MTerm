代理配置拆四字段 —— 主机 / 端口 / 用户名 / 密码（可交互，分段与眼睛可直接点）

现状问题
1单框 user:pass@host:port 把四种信息挤在一个字符串里：用户名含 : 无法表达（parser 按第一个冒号切）；密码里的 @/: 虽然能被 rsplit_once('@') 容忍，但用户不知道，写错只报「连不上」。
2密码以明文形态躺在地址框里（眼睛开关只属于密码型输入框，这一格享受不到），旁人扫一眼屏幕就泄露。
新方案
3拆成 代理主机 + 端口 一行、用户名 + 密码 一行（四框等宽 2×2）；端口天然数字校验（1–65535）；密码框复用 LabeledInput password 的眼睛开关与 Secret 存储。
4用户名/密码留空即匿名，提示语同步替换；「无」态仍整块收起（与现状一致）。
5存储格式不变：仍拼回 scheme://[user:pass@]host:port 存进 session.proxy，旧配置打开时由 split_proxy 升级为四段回填——零迁移成本，双实现可共存。
6错误不占表单流：端口非法只让端口框变红，文案进页脚状态行（与现有 #dialog-error-clear 字段红框 + 页脚提示同源，点击红字定位字段）——若在字段下插错误行，会把用户名/密码行往下顶，布局跳动。
7分段选中块滑动：chip 底色从各 SegOption 自绘改为容器内独立滑层 thumb，位置绑定选中索引 + animate x（Slint 1.x 原生属性动画，180ms ease-in-out）；文字颜色同步 animate color，切换即平滑滑动过去。

环节行为
代理协议归属旧「无 / SOCKS5 / HTTP」分段拆解：「无」→「直连」；SOCKS5 / HTTP 是代理的协议类型，收纳为「代理」分支内的两格分段（默认 SOCKS5）。存储不变：仍拼成 socks5://… / http://… 存 session.proxy。
互斥语义现有代码本就「跳板机优先、代理静默忽略」（ssh.rs:1040 jump 分支直接 return）；三分分段把这个隐藏规则变成看得见的结构，歧义从根上消除。切换分段即清空跳板链，还原虚线空态——每次进入都是干净起点。
跳板机链存储新增会话字段（如 jump-chain: 有序会话 id 列表）；旧单跳 draft-jump-index 迁移为链首一项，老配置无损。
多级连接connect_target_via_jump 从单跳扩为链式循环：逐跳 connect + auth，再经最后一级 direct-tcpip 到目标——UI 先行，连接层需同步扩展。
「过多」警告链长 > 2 显示 Theme.warning 暖橙提示（新增语义色）；非阻断，仅提示性能代价。
chip 悬浮提示悬停 150ms 后跟随鼠标、显示在光标上方（靠屏幕右缘翻到左侧、贴顶翻到下方）：名称 / 分组 / 备注非空才显示（空字段整行不出现），另有主机:端口 / 用户 / 认证方式 / 链中位置；落地复用 #foot-status-tip 卡片层浮层先例 + hover Timer，坐标取指针 move 事件，数据取自已保存会话摘要。
下拉候选悬浮「添加跳板机」候选 hover 时同样跟随鼠标在光标上方浮出同款信息卡（无链位行）——选之前就能看到这台机器是谁；实现上菜单容器不裁切、tooltip 挂在候选项内。
会话列表悬浮左侧列表行 hover 出同款信息卡（跟随鼠标、光标上方），内容 = 名称 / 主机 / 用户 / 认证 / 备注，去掉「分组」行——列表已按分组组织，卡里重复显示是冗余；数据即会话对象本身，零额外查询。
防环与排除下拉只列未入链的会话（「已在链路中」灰项不再出现）；全部会话都已入链时「＋ 添加跳板机」禁用（变暗、不可点）——防环由「只能从候选添加」结构保证。

存储与回填（格式不变，UI 拆装）
环节行为
保存（四个框 → URL）socks5://[user:pass@]host:port 拼回单字符串存 session.proxy；用户名为空则省略 @ 段。密码里含 @/: 也安全（不再依赖字符串约定，只是存储层格式）。
回填（URL → 四个框）split_proxy 升级：除 scheme 外再拆 rsplit_once('@') / split_once(':')，旧单框配置打开编辑对话框时自动落到四个框，无需迁移。
端口字段UI 层即时校验 1–65535（错误不放行「测试连接 / 创建」）；错误文案走页脚状态行（footer-status-text() 加一个 proxy-port-invalid 分支即可，行高常驻、点击定位字段），不占表单流。
密码存储复用 Secret 包裹与既有会话密码同管道；URL 反序列化时照旧 Secret::new。
