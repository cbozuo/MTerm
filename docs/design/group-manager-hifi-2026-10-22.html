Group Manager / Interaction Redesign

把「组」当对象管，而不是当过滤器用

现有弹框的功能已经齐了（双栏、拖拽、刷选、批量移动、删除条），问题在入口重复与组本身信息不足： 改名/删除在左栏悬停图标、右键菜单、右栏标题三处并存，删除裸图标紧贴改名，误点代价高； 而左栏一行只有「色点 + 名字 + 数字」，组名叫 2 时根本读不出里面装了什么。 本稿先把组级动作收敛成一条路径，再把组行升级成两行（名字 + 成员预览），最后把批量动作从菜单里提到列表底部。

01组属性只在头部一处双击组名改名（左右两处都认这个手势）、点色点改色、点垃圾桶删除——全部平铺在右栏头部，不再有 ⋯ 菜单。左栏只做导航与拖排序。
02两侧都是单行组行 36px：色点 + 组名 + 计数；会话行 36px：名称 + user@host 并排。一屏多看两三行，细节交给悬浮卡。
03选中即出现批量条勾选 ≥1 项，列表底部浮出「已选 N 项 / 移动到 / 移出分组 / 取消」，不用再去 ⋯ 里找移动入口。
04拖拽给足落点预期拖会话到左栏组行：整行转 accent 底、右端出现 +3 预览徽标；拖组行：组之间画插入线。
05右栏标题升级为组头部色点（点击即改色）+ 组名（单击即改名）+ 会话数胶囊左对齐成组；右端只留「全选 / ⋯」，不再让计数孤零零漂在右边。
06快捷键收进 ? 气泡底栏原本常驻四条按键提示，占掉将近一半横向空间。改为一个 ? 圆钮 + 首次打开自动展开一次。
07默认左窄右宽开箱左 320 / 右约 435（左栏只装色点+组名+计数，不需要那么宽）；中间 5px 分隔条可拖 220–480，双击回 320。
08顺序只靠看得见的操作整行可拖（行间浮出 2px 插入线）；悬停行尾出 ↑↓ 点一格，点的那条若已被勾选且勾了多条就整块移动。不做隐式键盘规则，也不设「排序方式」选择器。
09悬停看全貌名字被截断时，停 150ms 在鼠标右下角浮出信息卡并跟随移动：名称 / 主机 / 用户 / 认证 / 分组 / 备注，空字段不占行，贴近屏幕边缘时自动翻到另一侧。
10头尾各收一格标题与计数并成一行（58→52px）；搜索框吃掉中间余量、右端常备清除键（有内容才渐显）；Ctrl F 这类按键提示收进底部 ? 气泡，不在框里占位；操作结果写进底栏那行。

状态与边界

STATE必须存在且好看的态
  • 空组：右栏换虚线投递区「把会话拖到这里，或用批量条从其他组移入」，不让整栏空白。
  • 搜索无结果：两种语义分开 —— 全局都无命中时才说「所有分组里都没有匹配」+「清除搜索」；仅仅本组没有时给「本组没有匹配 · 其他分组还有 N 个」+「跳到「组 X」」。
  • 批量态：≥1 勾选 → 底部批量条；勾满当前列表时「全选」变「取消全选」。
  • 删除条：组内有会话 / 空组两种文案；空组时隐藏目标组下拉，只问「删除这个空分组？」。
  • 新建 / 改名输入：空名禁用确认，重名红框即时提示，长度>24 截断提示。
  • 组很多：左栏滚动，＋ 新建分组 吸底不随内容滚走。
  • 会话很多：右栏滚动；批量条浮在列表之上，不推挤列表高度。
GUARD刻意不做的事
  • 不做撤销栈：每次改动即时落盘，删除靠删除条这道唯一闸门，不做「撤销」假承诺（与现状一致）。
  • 不做「点击行打开详情」：行点击已经用于勾选，再叠一个"打开"会互相抢手势；看详情是悬浮卡的职责。
  • 删除不做确认弹框：删除条内联在右栏头部，就地选去向就地删，比再叠一层模态快一步。
  • 不在左栏做内联展开成员：会和右栏内容重复，违反「同一信息只出现一次」。
  • 默认组不可改名、不可删除、不参与排序：它是兜底桶而不是普通组，名字由程序固定（当前叫「默认组」），只有颜色可调。
  • 不做组嵌套：组是单层的，层级需求交给「来源」（本地/远程）与搜索。

待确认

  • 组行和会话行都单行了，行内只剩最关键的一行信息。组名如果是 1 2 3 这种随手起的名字，左栏就没有任何提示能看出组里是什么——要不要在组行 hover 时给一个小气泡列前几个成员？（右栏有悬浮卡，左栏目前没有。）
  • 删除组的默认去向是默认组（少一步操作），还是坚持现状「必须先手动选一个目标组」？我倾向默认组，因为删组时多数情况就是「这批先散着」。
  • 「默认组」现在可改色（品牌色兜底）。如果去掉颜色、只留空心圈，语义上更像「桶」而不是「组」，但会失去「给它也上色」这个可能被用到的能力。
  • 搜索要不要把地址（192.168.100.202）也纳入匹配？纳入后搜 IP 段能一把捞出整个网段的所有组。
  • 会话行第二行现在是 user || host（与实机同口径），结果一个组里 5 台有 4 台都显示 root，反而认不出是哪一台——本稿为此加了悬浮卡兜底。要不要干脆把第二行改成 user@host 或 host 优先？
