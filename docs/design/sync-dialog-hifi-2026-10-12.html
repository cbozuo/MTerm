其余保持行尾 +/− 图标、添加全部 / 全部移出、空态文案、双栏结构与底部确定/取消全部沿用上一稿，本稿不再重复评审。

§1改动总览

对照当前实机（ui/sync_input_dialog.slint，#sync-dialog-hifi 稿落地版）逐项说明改了什么、为什么。

改动现状（v1）本稿（v2）理由
频道切换四枚胶囊页签各自瞬切；选中 = 频道色淡染胶囊 ＋ 底部 2px 频道色条（下划线）。SegGroup 滑动分段（同新建会话「认证方式」）：单一外框 + 独立滑层，thumb 按 180ms ease-in-out 平滑滑动；下划线删除，选中身份全由滑块承担。与全应用分段语言统一；滑动给出"成员集在四个频道之间连续迁移"的空间感。胶囊 + 色条是两重选中标识，冗余——正是要删的。
作用域无。左栏固定为当前窗口的会话，多开时其余窗口够不着。标题区右侧「当前窗口 / 全部窗口」紧凑分段（display / copy 图标）；左栏候选集随作用域切换；跨窗口行附「窗口 N」徽标，悬浮卡同步多一行。配套：窗口 OS 标题带同一编号（MTerm · 窗口 N），任务栏/Alt-Tab 与徽标可互相对应。多开是常态使用方式；作用域必须显式可见、可预期。放标题区不占内容高度，双栏尺寸不变。编号徽标只有能被用户对应到桌面窗口才有意义——见 §3 窗口编号红线。
行悬浮信息卡行只有色点 + 标题；"202 / 202-1 / 202-2"这类简称无法辨别目标主机；tab 卡与同步卡没有用户/认证行。tab 同款键值信息卡：名称 / 主机 / 用户 / 认证 / 组别（色点，未分组不显）/ 备注 / 频道（含「已暂停同步」附注）/ 窗口（跨窗口行）。未加入与已加入两栏都有。与左侧成员卡、新建会话跳板机卡的信息量对齐（那两处已有用户/认证）；悬停即可确认目标，不必"先加入再试错"。同名会话（202-1）靠 主机+用户 辨别。
行内容与左栏构成行显示会话名称；左栏 = 非当前频道成员（其他频道成员只有一颗同款色点，身份不明显）。行主文本改主机（左对齐；名称不占行，悬浮卡里有）；左栏仍排除当前频道成员（右栏就是，不重复）；其他频道的成员行标 tab 同款字母药丸（频道色底 + 白字字母，无文字描述）。会话常以简称命名，主机才是辨别关键；当前频道成员左栏再列一遍与右栏重复；字母药丸与 tab 页签同一语言，一眼认出"这个会话已在频道 C"。
滑块配色选中胶囊 = 频道色 α0.15。thumb 染频道色（α0.16，亮色 0.13），选中文字与成员数徽标同染频道色。频道色承载"这是频道 A/B/C/D"的身份语义，一眼可辨当前在配哪个频道；作用域分段保持标准 chip/accent，两段各管一件事不互抢。
列表滚动两栏是裸 Flickable：滚轮/拖拽能滚，但没有滚动条指示，会话多时没有"下面还有"的暗示。两栏换 ScrollView（app 既有惯例：确认弹框 / 编辑器 / SFTP / 设置面板都是）：滚动条自适应——内容不溢出不出现，溢出才出现。与全应用滚动语言一致；活动会话多时位置感明确，滚到头即"没有更多"。

§3交互规格红线

几何与动效参数全部对齐现有实现，落地时不引入新语言。

  • 频道分段（SegGroup 同构）：容器高 36px / 圆角 10 / 1px border-control / field 底 / 内衬 3px / 段间 2px；thumb 圆角 7，按无量纲格位插值（#seg-thumb-progress 同款），180ms ease-in-out。段 = 色点 10×10 + 频道名 12px + 成员数徽标 17px。
  • 选中染色（已定稿：频道色）：thumb = 频道色 α0.16（亮色 0.13）；频道名 600 字重染频道色；徽标底 α0.24（亮 0.18）字染频道色。未选中段悬停 = bg-hover，文字提升一档。下划线指示条删除（sync_input_dialog.slint:80-89 整段）。
  • 作用域分段：标题区右侧紧凑档，高 28px / 圆角 8 / 内衬 2px / thumb 圆角 6；display / copy 13px 图标 + 文案；标准 chip + accent 语义（与频道段区分：作用域没有频道身份）。默认「当前窗口」。
  • 作用域语义：只过滤左栏候选集；右栏成员跨窗口常显（成员已在频道里，滤掉会造成"在频道里却看不见"的困惑），非本窗口成员带窗标。「全部窗口」下左栏头文案切换为「全部窗口中的会话」，跨窗口行附「窗口 N」徽标；添加全部只作用于可见候选。
  • 窗口编号与可辨识性：编号 = WindowRegistry 的 window_id（1 起、稳定不回收——关掉中间窗口后新窗口编号继续涨，数字跳跃本身即"更早打开的窗口"的线索）。徽标数字必须与 OS 层可对应：窗口标题同步带同一编号（MTerm · 窗口 N，当前所有窗口都是静态 "MTerm"，app.slint:790，任务栏/Alt-Tab 无法区分——这是徽标有意义的前提，属本次配套改动）。无边框自绘标题栏不受影响：标题只出现在任务栏悬停 / Alt-Tab / shell 层。任务栏表现：单进程多窗口默认合并为一个按钮，按钮标签跟随活动窗口标题，悬停缩略图与 Alt-Tab 每扇窗口各显自己的「MTerm · 窗口 N」——都能对上号。边界：直接双击 exe 再启动会跑成独立第二进程（plain relaunch 不转发，single_instance.rs），两个进程的 registry 各自从 1 编号、互相不可见——此场景下「全部窗口」实际为本进程内全部窗口，跨实例编号可能重号（罕见路径，v1 接受并如实降级；后续可扩展 IPC 互相发现）。后续可选：允许用户给窗口命名（如「生产」「测试」），徽标与悬浮卡优先显示名字、回退编号。
  • 悬浮信息卡（tab 同款）：150ms 首锚 + 悬停移动跟手（pointer-event move），移开即清；定位 = 光标 +10px 右、上距 8px，右缘越界（x+10+w > 宽-8）左翻，上缘越界（y-h-8 < 8）下移 +20px。视觉 = bg-elevated 底 / 9px 圆角 / 1px border-subtle / 24px 投影 / 键值单行连排 fs-xs / 行距 2px（#session-card-twin 参数）。
  • 卡片行序：名称 → 主机（空不显）→ 用户（空不显）→ 认证（空不显，显示名同新建会话分段：密码/键盘交互/私钥）→ 组别（未分组不显；组色点 + 组名，色点与左侧组头/标签底条同源）→ 备注（空不显）→ 频道（slot≥0 才显，「已暂停同步」附注）→ 窗口（仅跨窗口行）。离线成员标题尾缀「（离线）」并整行置灰，与现行为一致。未加入（左）与已加入（右）两栏都有卡；左栏中已属其他频道的会话，卡里如实显示其所属频道（色点/药丸已如此暗示）。配套：用户/认证行同步补到 tab 悬浮卡（左侧成员卡与跳板机卡已有）；TabInfo/SyncSessionInfo 需补 user/auth（组名补 group_name——Rust 侧 display_group_of 等数据现成）。
  • 跳板机 tip 卡颜色（已随评审落地）：新建会话跳转链路的悬停卡，Host/User/Auth/Group/Note 五行 text-secondary → text-primary，与名称行同亮度（#hover-card-uniform 同款收敛）；「链路中第 N 跳」行（accent 小字）保持不动。
  • 候选集构成：只列真会话——welcome tab（新标签页）不入列。实机现状是 open-dialog 把全部打开 tab 塞进模型（sync_input.rs:54），welcome tab 的 session_id 为空，既没有可同步输入的终端，加频道后 apply 按 session_id 去重还会互相冲突；落地时 Rust 侧按 kind == "welcome" / 空 session_id 过滤（离线持久成员的补行逻辑不受影响）。
  • 行内容：行主文本 = 主机，左对齐（host 为空回退标题，离线成员整行置灰）；名称不占行——悬浮卡里有完整身份。行尾动作不变：左 + / 右 −。
  • 左栏构成与字母药丸：左栏 = 作用域内排除当前频道成员的候选（当前频道成员只在右栏，不重复渲染；加入/移出时行在两栏间迁移）。左栏中其他频道的成员行带 tab 同款字母药丸（tabs.slint channel-letter 逐像素一致：14×14px / 圆角 4px / 频道色实底 / 白字 9px 字重 800，无「频道 X」文字描述），色点照旧。
  • 列表滚动（自适应滚动条）：两栏列表纵向滚动，滚动条按需出现——内容不溢出完全不占位，溢出才出现（mock 为 overflow-y:auto，8px 圆角 thumb、与 field 底融合）。落地 = 裸 Flickable 换 std ScrollView（sync_input_dialog.slint:311/400 两处），与确认弹框 / SFTP / 设置面板同款；折叠行（0px clip）方案与 ScrollView 兼容，不需改。
  • 弹框内翻转：卡渲染在 SyncInputDialog 内部顶层（弹框 clip:true，翻转公式天然保证不越界），不与 tab 卡共用根层槽，避免模态期间串层。

§4落地要点（Slint / Rust 映射）

SEG-REUSE组件复用
SegGroup/SegOption 目前是 session_dialog.slint 文件私有 → 提升到公共文件（widgets.slint 或独立 seg.slint）供 sync_input_dialog import。SegOption 增加可选 active-tint/active-fg 属性：频道段传频道色，作用域段不传走默认 chip/accent。频道的 chip 底改由滑层绘制，SyncSlotTab 自绘背景与下划线整段删除。
STATE-SCOPE状态扩展
SyncInputState 增加 scope: int（0=当前窗口，1=全部窗口）；SyncSessionInfo 增加 win-id/win-label、group-name/group-color-hex、user/auth 字段（空 = 当前窗口 / 未分组 / 不显行）。多开为单进程多窗口（--new-window 经 single-instance IPC 转发到主实例后仍进程内 open_window），跨窗口枚举 = 进程内遍历 WindowRegistry（core.rs:90，自增稳定 id），无需跨进程查询。同时修候选集：open-dialog 过滤 welcome tab（空 session_id）。slot-counts 语义不变（仍为每频道成员总数，Rust 重算）；scope 切换时 Rust 重填 sessions 模型。
WIN-TITLE配套改动
窗口标题从静态 "MTerm"（app.slint:790）改为 MTerm · 窗口 N（N = window_id + 1，各窗口在注册时写入一次即可，标题不变无需跟踪）。任务栏合并按钮标签跟随活动窗口、悬停缩略图/Alt-Tab 各显各的编号——「窗口 N」徽标由此获得锚点。无边框自绘标题栏不受影响。边界：plain relaunch 的独立第二进程与主进程互不可见（无发现机制），「全部窗口」降级为本进程窗口、编号可能跨进程重号，v1 接受；窗口命名（用户自定义名）为后续可选项：命名后徽标/悬浮卡/标题都优先显示名字。
APPLY确定语义
确定时按槽位持久化不变；跨窗口成员的写回由 Rust 按各窗口广播（新窗口打开时也按持久化结果恢复成员关系）。若评审认为需要，可后续在底部加一行作用域提示文案，本稿暂不加，保持底部干净。
CARD悬浮卡
SyncRow 增加 card-out/card-clear 回调（SingleTab 同款：150ms Timer 首锚 + pointer-event move 跟手 + changed has-hover 清除）；卡在 SyncInputDialog 内部顶层渲染，行序 = 名称/主机/用户/认证/组别/备注/频道（暂停附注）/窗口，数据直接读行内 SyncSessionInfo（认证显示名与新建会话分段同一张表），无需新模型。tab 悬浮卡同步补 用户/认证/组别 三行（TabInfo 补 user/auth/group-name）。
JUMPTIP已落地
跳板机 tip 卡（session_dialog.slint）Host/User/Auth/Group/Note 五行 text-secondary → text-primary，与名称行同亮；「链路中第 N 跳」accent 小字不动。cargo check 已通过，随下次构建生效。
SCROLL列表滚动
sync_input_dialog.slint:311/400 两处裸 Flickable → std ScrollView，滚动条按需出现；折叠行（0px clip）方案兼容，不需改。
