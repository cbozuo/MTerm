03

匹配行被浮层挡住怎么办

跳转居中 + 滚不动时下移让位 + 拖动手柄（手动钉位）

Enter/↑↓ 跳转时把当前匹配行滚到视口中部（IDEA/VS Code 同款），从根上不落在浮层底下；仅当滚不动（匹配在回滚区顶端，或 alt 屏无回滚——首行是典型）时，面板自动下移到匹配行下方让位，匹配变化重新判定、不相交即回锚位。(v3.6) 锚位 = 用户钉住的位置：没拖过手柄时是右上默认锚位，拖过之后「回锚位」回到钉住处——跳转永远不把面板送回右上角，否则钉位被第一次跳转就清掉，等于白钉。

⠿按住手柄拖到哪，钉到哪
拖动中：光标握拳、手柄 accent 高亮、阴影加深；距四角 ≤12px 磁吸贴角；双击手柄回右上默认锚位。拖到哪，居中滚动 / 下移让位照样生效。

拖动手柄 · 细则

静默
悬停 · 张开手 (grab)
按住 · 握拳 (grabbing)

手柄：面板最左 ⠿，贴左缘、与输入框等高的热区（左右留白对称且最小）；光标悬停 = 张开手（grab），按住拖动 = 握拳（grabbing）；高亮跟随主题强调色（悬停淡染 / 按住 accent 描边）。拖动中输入框保持焦点，松手直接继续打字。

范围：自由拖动，clamp 在终端区矩形内——不会拖上侧栏 / 状态栏。

磁吸与复位：靠近四角 ≤12px 自动贴角；双击手柄回右上默认锚位（双击复位是项目惯例）。(v3.6) 「回锚位」（§03 ④）与「复位」是两件事：前者回到钉住的位置，后者清除钉位回右上默认。

记忆：位置只记本次查找会话，Esc / ✕ 关闭即复位，不持久化——避免「上次拖到角落，这次凭空在那」。

量级 S：TouchArea.moved 更新面板 x/y。项目先例齐全：滚动条拖拽、分组跨栏拖动、#settings-drag-ghost 像素对齐。

规则汇总（v3.6）

① 起始当前匹配 = 离当前视口最近的命中：视口内有 → 视口内第一个；没有 → 从视口向下找最近的；再没有才向上回卷。逐键输入不重跳——只在「当前视口内一个命中都没有」时才移动视图；敲第二个词不再跳动。(v3.6) 这条替换现网 scroll_to_first_find_match「无可见匹配 → 跳全缓冲第一个」的兜底：配合默认循环查找，那个口径会把正在打字的人拽到回滚区顶端。

② Enter / ↑↓ / 手动跳转 → 滚动目标 = 匹配行 − 行数/2（能滚就居中）。

③ 滚不动（回滚区顶端 / alt 屏）且匹配与锚位相交 → 面板下移到匹配行下方（200ms 动画，200ms 去抖；输出流刷屏不触发位移）。

④ 匹配变化后重新判定，不再相交 → 回锚位。(v3.6) 锚位 = 用户钉住的位置（未拖过 = 右上默认），不是永远右上角。

⑤ 点击高亮成为当前匹配 → 不滚动（那一行本来就可见）。(v3.6) 仲裁：单击、未拖动、且当前会话未开鼠标跟踪（或 Shift+单击）时才生效；mouse-tracked 应用（htop/btop/mc）与拖拽选区照旧，双击选词不受影响。

三层心智：内容挪给你看（居中）→ 面板挪开（下移让位）→ 用户手动钉位（拖动手柄，见上）。降透明方案退役；三项都是 S 级改动。

06

边界口径

评审补全 · 一条一句话，实现时不再临场发挥

布局与降级

① 窄面板降级：面板宽 < 360px 时计数文字缩为「n」，< 280px 时隐藏 Aa / 正则 / 历史（键盘仍可用），只留 输入 + 清空 + 关闭 + 手柄；断点只砍展示，不改行为。

② 滚动条共存：右上锚位 right:8~10px 会压住右缘滚动条顶部（滚动条贴右缘 10px、宽 8px）——接受此遮挡（查找是临时态），不为它挪锚位。

③ 下移让位的死角：alt 屏 + 匹配在末行 + 面板钉在底部时「下移」放不下 → 允许上移到匹配行上方（同一套判定，方向相反）。

匹配与数据

④ 跨软换行：首版只做行内匹配；被终端软换行截断的词不算命中（现网口径一致），写进验收防止误报。

⑤ 正则无效时：保留上一次有效结果的计数与高亮，计数位红字「正则无效」；修正后恢复。

⑥ 切 Aa / 正则后：当前匹配重置为原位置附近的最近命中（优先视口内），不跳回开头。

⑦ 查询入历史：Enter 或「带词关闭」时写入最近 10 条；去重、最近在前；带 Aa / .* 标记。

状态与生命周期

⑧ 关闭后的滚动位置：Esc / ✕ 关闭时留在原地，不回 live bottom——用户经常是顺着查找读日志的，被弹回底部等于丢位置。

⑨ 重开回填：再次打开时回填上次的查询词（含开关状态）但不自动滚动；仅当视口内无命中才按 §03 ① 跳最近命中。

⑩ 多标签 / 分屏：查找状态按 tab 隔离（现网即如此）；切 tab 时面板保持打开并显示该 tab 的词，各自独立的高亮与当前匹配。

⑪ 可及性：↑↓ / Aa / 正则 / 历史 / 手柄补 accessible-role: button + accessible-label；清空键已有先例（@tr("Clear search")），同套走 i18n。
