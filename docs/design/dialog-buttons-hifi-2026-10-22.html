同一个「页脚按钮」，五种写法

这五张截图里的按钮，外观看着差不多，参数没有一项是对齐的： 高度 30 / 36 / 38，圆角 4 / 7 / 8 / 9，字号 12 / 13， 宽度策略 定宽 64 / 定宽 80 / 定宽 88 / 内容宽，主按钮文字色 白 / 深青 两种。 连「取消」都要么有边框、要么没有。

这一版不做全应用推广，只把这五处收成一套。所有效果都只用 Slint 能表达的属性—— 矩形、圆角、1px 边框、纯色或半透明填充、文字与 SVG 图标； 没有阴影、没有渐变、没有毛玻璃，稿子里的每一条都能直接写成 Rectangle 属性。

① 新建会话 session_dialog ② 取色器 color_picker ③ 确认弹框 confirm_dialog ④ 同步输入 sync_input_dialog ⑤ 输出高亮 highlight_dialog

一个被忽略的关键项：主按钮的字色白字在 #1FC8B4 上对比度只有 1.9:1

02

一套规格：三个角色 × 五态

只定义 3 个页脚角色（主 / 次 / 破坏）+ 1 个文字链接，尺寸统一到 34 高 / 8 圆角。 34 是这五处（30 / 36 / 38）的中间值，也与弹框内输入框、chip、下拉同高，页脚与内容区才咬得齐。

过渡一律 120ms。禁用态只换灰阶，不叠加整体透明度—— 半透明会让按钮透出下面的分界线。

尺寸为什么是 34 / 8

取法值理由
五处现状30 / 36 / 38中位数 36，但 30 占两处
弹框内控件高度32输入框 / chip / 下拉
页脚取值34比内容区控件高 2px，形成层级的收尾
圆角8= 输入框 / chip / 下拉同值

页脚按钮比同页输入框高 2px：视觉上「压得住」底部，又不至于像 38 那样把整块页脚撑高。

04

落成代码：一个组件 + 五处替换

上面所有渲染效果，都由下面这个组件产生。没有一条属性超出 Slint 的能力： 位置靠 HorizontalLayout，底色靠 background，边框靠 border-width / border-color，圆角靠 border-radius， 悬停靠 TouchArea.has-hover，过渡靠 animate。 

// widgets.slint —— 页脚按钮的唯一实现（新增，替换五处）
export component FootButton inherits Rectangle {
    in property <string> text;
    in property <string> glyph: "";        // 可选，图标在文字左侧
    in property <bool> primary: false;      // 主操作 = accent 实心
    in property <bool> danger: false;       // 破坏性 = 红描边
    in property <bool> disabled: false;
    callback clicked();

    height: 34px;
    min-width: 76px;
    border-radius: 8px;
    border-width: 1px;
    border-color: primary ? transparent
        : danger ? (ta.has-hover ? Theme.danger : Theme.danger-strong)
        : (ta.has-hover ? Theme.border-strong : Theme.border-control);
    background: disabled ? Theme.bg-elevated
        : primary ? (ta.pressed ? Theme.accent-pressed
                    : ta.has-hover ? Theme.accent-hover : Theme.accent)
        : danger ? (ta.has-hover ? Theme.danger.with-alpha(0.10) : transparent)
        : (ta.pressed ? Theme.bg-active
            : ta.has-hover ? Theme.bg-hover : transparent);
    animate background, border-color { duration: 120ms; }

    HorizontalLayout {
        padding-left: glyph == "" ? 18px : 14px;
        padding-right: 18px;
        spacing: 7px;
        if glyph != "" : Icon {
            glyph: root.glyph;
            size: 15px;
            tint: disabled ? Theme.text-muted
                : primary ? Theme.accent-on
                : danger ? Theme.danger-strong : Theme.text-secondary;
        }
        Text {
            text: root.text;
            // 主按钮用深青，不用白：白字压在 #1FC8B4 上只有 1.9:1
            color: disabled ? Theme.text-muted
                : primary ? Theme.accent-on
                : danger ? Theme.danger-strong
                : (ta.has-hover ? Theme.text-primary : Theme.text-secondary);
            font-size: Theme.fs-md;   // 13px
            font-weight: primary ? Theme.fw-strong : Theme.fw-regular;
            vertical-alignment: center;
        }
    }
    ta := TouchArea {
        enabled: !root.disabled;
        mouse-cursor: root.disabled ? default : pointer;
        clicked => { root.clicked(); }
    }
}

// theme.slint —— 需要新增的两个语义色（当前没有）
out property <color> accent-on: #06231F;      // accent 上的文字色
out property <color> danger-strong: #DC4B44;  // 已有

验收方式

  • 改完逐个弹框真机截图，与本文档「修改后」并排比对；重点看页脚按钮底边是否与弹框底线等距。
  • 五处页脚高度统一后应都是 34 + 上下 12 = 58，可用离屏探针断言（参照 tests/sidebar_edge_line.rs 的取像素做法）。
  • 主按钮字色可用对比度脚本校：#06231F on #1FC8B4 应 ≥ 4.5:1（实测 10.4:1）。
  • 深色 / 亮色两套主题都要过一遍——accent-on 在亮色主题下需要按现有 dark ? … : … 分支取白。
口径：本文只覆盖五张截图对应的弹框页脚按钮与它们的邻近控件（分段、频道栏、文字链接、关闭键），不做全应用推广。
能落地：所有视觉差异都由 Rectangle 属性产生；没使用阴影、渐变、滤镜。稿子里唯一不是 Slint 属性的是页面自身的排版（文档样式）。
不做：不改弹框结构、不动语义色板、不给按钮加阴影或外发光、不为统一把 34 再拉高到 38。
