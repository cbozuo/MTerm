IME(中文输入)策略 自绘光标下唯一的落地风险点,给定稿方案

ASCII / 可打印字符:FocusScope key-pressed 直接插入 rope,零延迟。
IME 组合期:光标处弹一个 28px 高的「输入胶囊」浮层(真实 TextInput,mono 字体,跟随光标坐标,宽随 preedit 文本)——Slint TextInput 原生承接 winit 的 IME 组合/候选/提交链,不用动引擎、不依赖 vendor patch;提交(preedit 结束)后整段写入 rope,胶囊关闭。
兜底退路:若实测组合期候选窗定位有偏差,胶囊退化为状态栏上方固定位置的输入条(旧浏览器风格),功能不受影响——两档都只依赖 PopupWindow + TextInput,无引擎改动。

分期

一期 · 核心虚拟化渲染 + rope + 语言自动识别 + 高亮(tree-sitter 8 个:java/sql/json/yaml/toml/bash/xml/python + 行级:log/nginx/ini/properties/env/Dockerfile/md)+ 浮层查找 + 自绘光标选区键入 + 保存回传进度 + 大文件只读模式 + 格式化(JSON/SQL/TOML/XML/nginx,Java 缩进归一)+ 编码自动检测(GBK/GB18030)
二期窗口内多文件 tab + 折叠 + 替换增强(Aa/全词/正则)+ 转到行浮层 + 右键菜单 + 折行开关
三期 · 选做远端文件重载提示(mtime 对比)+ LF/CRLF 切换 + 更多语言 grammar(按需追加 tree-sitter crate)

不做清单(防盲设计)

  • minimap:Zed 也没有;软件渲染每帧重画缩略文本代价过高,收益低
  • LSP / 智能补全:远端场景无语言服务,一期二期都不做
  • 多光标:Zed 有,但虚拟化 + 选区模型复杂度翻倍,明确砍掉
  • 自动折行默认开:与虚拟化行高恒定冲突,只作开关且默认关
  • 语法检查 / 悬浮文档:同 LSP,远端场景无意义
与现有代码的衔接:保留 editor_window.slint 的窗口框架(36px 标题栏 / 保存钮 / 关闭钮 / 调整柄 / FocusScope 快捷键)与 SFTP 面板 edit() 回调入口、保存回调链;退役全文 TextInput、行号 for 全量渲染、逐行测量 TextInput、常驻查找条、editor-content/editor-lines 两个全量属性(替换为窗口模型 + rope 回调族)。主题/壁纸/DPR 同步链(sync_editor_theme)原样复用。
