C现状 → 新案 对照说明

1头部工具化

「Quick connect」大标题 + 全宽「+ 新建会话」主按钮，压成一行 38px 工具条：左「会话 · N 台」，右三个 24px 图标钮（新建 / 导入 ssh config / 收起）。新建降级为图标钮——它是低频动作，不值得常驻一个实心主按钮。

标题 28px 高 + 主按钮 30px 高共占两行，列表可视区少 ~72px

2组头去底色、权重重排

去掉组头整行 bg-panel-alt 底色块，层级改由三件事表达：组名 600 字重提亮为 text-primary、成员缩进 + 组色脊线、组间净距 8px。chevron 从组色改为灰色 14px——组色收敛到文件夹 + 脊线两处，不再三处同色（箭头/文件夹/脊线）互相抢。计数徽章去掉胶囊底，改为纯文字淡色。

底色块 + 组色×3 + 胶囊徽章，视觉手段过多、窄栏里显重

3连接状态点移到行右缘

黄/绿状态点从协议图标右上角小徽章，改为行右缘 6px 圆点：右缘是扫读列表时视线的固定停靠位，多台在线时一列绿点可比对；绿点带微光晕。协议图标保持纯语义（协议种类），不再混入状态语义。

状态点叠在 16px 图标角上，黄绿小点与图标糊在一起、难以扫读

4新增「正在使用」常驻态

当前 tab 正在查看的会话，在树里给 accent 淡底 + 左缘 2.5px accent 圆头条。这是现版本缺失的状态——开了 5 个连接后，树里完全看不出自己站在哪台机器上；标签页有 accent 顶线，树里给同语义的左条，两处互相印证。

树里只有 hover/右键两种临时高亮，无任何常驻选中态

5底部信息条

新增 30px footer：「6 组 · 13 台 · 2 台在线」 + 右侧全部折叠 / 全部展开两个图标钮。原来这两个动作只藏在空白处右键菜单里，不可发现；面板也借它形成「头—内容—底」闭环，列表滚动区边界更清晰。

全部折叠/展开仅空白右键可达；面板底部戛然而止无收边

6保留不动的打磨成果

组色脊线（2px、悬停整条联动点亮）、├ 横枝、拖拽 ghost 卡 + 组色落点空槽 + 邻行弹簧让位、悬停信息卡、右键菜单集中浮层、空组「空分组」占位——这些是多轮反馈磨出来的，形态与机制原样保留，只随行高微调。
