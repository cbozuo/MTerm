05

Slint 落地表

按 Slint 1.18.1 的 PropertyAnimation 能力写：支持 duration / delay / easing / enabled；没有 3D transform 与 mask。表里只列可写进代码的落点；宽度示例按左栏 240px / 右栏 220px（ui/app.slint:1698、:1109），快捷面板 260px。

1.18.12 个坑
形态写法片段成本风险 / 备注
瞬时// 不写 animate，宽度直接赋值 width: root.collapsed ? 0px : 240px;易没有过渡；最稳，但用户看不出收去哪了。
推挤width: root.collapsed ? 0px : 240px; animate width { duration: 240ms; easing: ease-out; }易最推荐；长列表用 clip: true 防溢出。
吞没// 外层收宽，内层固定宽 width: root.collapsed ? 0px : 240px; clip: true; animate width { duration: 320ms; } // 收口描边用 Rectangle.border-width 过渡中内层固定宽，短暂裁切内容；扫描线需额外描边。
手风琴// 每行 height 归零，delay 递增 height: root.collapsed ? 0px : 32px; animate height { duration: 140ms; delay: row-index * 18ms; }中行多时尾帧拖尾；总时长要压到面板收宽之前。
归巢// 行位移到按钮位置并淡出 x: root.collapsed ? target-x : 0px; opacity: root.collapsed ? 0 : 1; animate x, opacity { duration: 140ms; delay: row-index * 18ms; }中偏高行级坐标跨容器易错位；target-x 需按窗口实时算。
果冻animate width { duration: 380ms; easing: cubic-bezier(.34,1.56,.64,1); }中过冲会短暂挤压终端；宽度需留 8px 余量。
形态 chips// 6 选 SegGroup，点击直接写枚举；一套作用两侧 property <string> shape: "push"; // 复用公共 SegGroup（ping 弹框同款），无自绘刻度易枚举字符串与配置键直通
配置键panel_anim_shape = push panel_anim_ms = 240 panel_anim_easing = smooth panel_anim_reduced_motion = true易一套配置作用两侧；旧 *_left / *_right 分侧键不再需要
坑 01 · 首帧门卫

首帧别从 0 开始

启动恢复布局时，animate 会从 0 播到目标宽。加 enabled: root.first-frame-done，首帧后置 true。

坑 02 · 吸附冲突

动画期间停 snap-to-device

面板拖拽吸附若和收展动画同时跑，宽度会被两边写。动画开始停吸附，终止帧再吸附一次。

兜底 · reduced-motion

系统减少动效 = 0ms

监听系统设置，命中时把所有 duration 归零，不做形态降级；布局逻辑保持不变。
