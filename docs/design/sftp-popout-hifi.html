② 落地结构映射

  • 新增 sftp_window.slint 顶层壳：标题栏 + 扩展工具栏 + 内嵌 SftpPanel 转发；面板本体在「主窗终端区底部 dock」与「独立窗口」之间搬宿主，同一份 ModelRc 不重建

  • 列宽 / 树宽 per-session persist（S.colW / S.colOrder，同 sftp-tree-width 契约）；列头右缘可聚焦 separator + 键盘微调
  • ⚠ 三套弹框规格差异待拍板：ConfirmDialog（380px/radius-lg/可拖拽）· #69 prompt（340×178/radius-md）· #84 chmod（320×270/三组复选）—— 稿内统一按 ConfirmDialog 画，落地前先决定「统一 or 分立」

③ 交互口径要点（✦ 定稿）

  • 「当前行」与「已勾选」分立：当前行只留左强调条，勾选只由复选框 / Ctrl+A / Shift 产生，右键不写勾选态
  • 树的亮起 = 当前路径链（当前目录 + 各级父目录）；展开与否只由图形（folder ⇄ folder-open）表达，展开集合由 current-path 推导
  • 多传输右下角 = 一块聚合：⇅ N 项 · ↑ 聚合 · ↓ 聚合（速率按方向合并；空闲淡出；悬浮逐条清单；点开队列抽屉）
  • 下载统一入口 requestDownload()：目录选择 → 同名冲突（rfd 原生框改应用内弹框）→ 入队；上传两段式 upload-preflight → upload-exec
  • 文件行高：实机 24px，稿内 28px = 弹出窗多列信息表行高（稿内新增，已拍板保留）
  • 外壳布局照实机：左会话树 · 中终端区（SFTP 面板停靠其底部）· 右状态面板；面板因此只拿到终端区那一列的宽（再减掉自己的目录树），列放不下 → 横向滚动条避免不了（表头与数据行同一内容层，一起滚，天然对齐；滚动条与竖条同一套自绘口径：4px 拇指）
  • 文件列表每列都可拖间距（含名称列：名称|类型 的边界同样可拖，宽度记在 S.colW.name，区间 120–600），且边界全高可拖（同款树分隔条：沿整条边界移动就亮出同款竖线，按住拖动即调列宽；表头那一段另有可聚焦手柄，支持键盘微调）。边界 7px 带内以「调列宽」优先，行的拖拽（下载）不受影响：手柄压在列边界上，hover（或键盘聚焦）即出一条贯穿「表头 + 全部数据行」的全高竖线，口径与目录树分隔条 #treeDivider 一致；拖动中另有导引线 + 宽度读数，Esc 取消 / 双击自适应 / ←→ 微调；拖动时只保留导引线一条（悬停竖线让位，不与导引线并存）
  • 过滤框 = 项目 SearchBox（ping_dialog.slint）：高 28 / 圆角 6 / 底 popup-field / 1px 边 border-control；聚焦 = 边框 accent-solid + 3px accent-soft 外环（实机是独立外环矩形，稿内用等尺寸 box-shadow）；搜索图标内置在框里（12px muted，文字自 x=27 起）；有字时出 ✕ 清空钮（16px 圆钮、✕ 9px）；点击框外即离焦 —— 收条但保留过滤结果，工具栏搜索钮转为「过滤中」态（accent + tip 显示过滤词），点它再打开编辑
  • 「跟随 cd」是实开关（实机 src/app/core.rs 的 follow_cd，命令面板可搜「SFTP 跟随 cd」）：状态栏里的芯片点一下即切换（绿点=跟随中 / 灰点=已关），稿内用终端里那条可点的 cd 演示行体现效果 —— 开着时面板跟着跳到该目录，关着时面板不动并在状态栏说明「跟随 cd 已关闭」
  • 悬浮提示统一走一个浮层：所有带 data-tip 的元素共用一个 .tip 浮层（原先只有工具条钮/窗口钮/状态栏芯片几类有 ::after 提示，其余都不显示）；浮在目标上方 8px、居中，顶到屏幕上沿自动翻到下方，横向夹在视口内，120ms 延迟（掠过不闪），滚动/缩放即隐藏
  • 悬浮底色全库统一一个令牌：项目同款 Theme.bg-hover = accent-solid.darker(0.10) 再 8% 透明叠加（暗 rgba(28,180,162,.08) / 亮 rgba(28,106,96,.08)）—— 行 / 菜单项 / 工具条钮 / 标题栏钮 / 列表头齿轮 **全部同款**，不再有"白色 4.5% 叠层"与"不透明灰"两套
  • ⋮ 悬浮只染图标色：行尾「更多」与组头/成员 ⋮ 悬浮 = 图标染强调色、不加背景块（实机 #kebab-accent-tint：染色不等于垫底色，免得行带被切出一块）
  • 底部状态栏（设计新增 —— 实机 ui/sftp_panel.slint 已删底部状态条 #sftp-bottom-status：那条只是重复路径，路径在工具栏就能改）：三段式 = 左「当前目录计数：项数 / 已选 / 隐藏」· 中「操作结果槽（一次性回执）」· 右「跟随 cd / 下载目录 / 传输聚合」；空槽一律不占位（结果槽此前只用 opacity:0 隐藏，文字仍在 DOM 里 → 把两段内容撑开 140px 空洞）；标记类一律轻量（状态点 / 图标 + 11px 次级字， hover 才出底色），不再用实心强调药丸
  • 弹框分两种脸，都照项目：表单类（新增文件 / 新建文件夹 / 添加隧道）按 session_dialog / ping_dialog —— 头栏 54px（30×30 圆角 7px 强调色淡染图标块 + 标题 18px 粗体 + 右上角 ✕ 关闭键，DialogClose 口径：常态灰 × / 悬停红底白 ×）、卡片 16px 圆角(radius-xl) + hairline 线（暗 line-2 / 亮 #b9b9c2）；确认类（删除确认 / 上传冲突）按 ConfirmDialog —— 10px 圆角 + border-strong。两类都支持空白处按住拖动卡片（位移 > 3px 才算拖，否则算点击；交互元素上不触发）
  • 弹框一律按项目 ConfirmDialog 口径：卡片宽 380 / 圆角 10(radius-lg) / 内距 20 / 块间距 12；头部 = 图标 18 + 标题 18(fw-strong)；正文 13px 次级色；页脚右对齐、间距 8（取消 Ghost + 主钮 Primary）。输入框 = MiniInput（session_dialog.slint）：高 34 / 圆角 8 / 聚焦 = 边框 accent-solid + 3px accent-soft 外环（与 SearchBox 同一语言）/ 占位符即标签，无标签列；点框外即失焦（弹框不关，只收焦点）。弹框内块间距 12（实机 ConfirmDialog 的 VerticalLayout spacing）；分段条与输入框同一栈（间距 8 —— 否则聚焦环会压到上一条的底线）。弹框内的多段选择 = 非 compact 档 SegGroup（高 36 / 圆角 10 / 内衬 3 / 段高 30 / 段内无边框、选中透明透出滑层；选中文字只换 accent 色，不加粗）
  • 按钮一律用项目规格：文本钮 = GhostButton/PrimaryButton（高 30 / 圆角 6=radius-md / 最小宽 80 / 内距 0 16 / 13px；主钮 = 强调实心 + 白叠 hover 12% · 按下 22%，不整底换色）；危险钮 = DangerButton（圆角 4 / 内距 0 14 / 红 → hover #ec6a6a → 按下 #c44a4a）；工具条图标钮 = IconBtn（26×26 / 圆角 4 / 图标 13 / 常态 text-primary / hover bg-hover / 激活态 = accent；成组的图标钮贴连：组内 spacing 0 + 圆角归零 + 定宽 30px → 悬浮高亮连成一条整带，中间不留缝（实机 WinBtn 语言：视觉间隔由字形留白提供） —— 如传输队列抽屉展开时 ⇅ 转 accent 色；实机 #theme-dedupe §5 A 类：常态前景色 · 激活 accent · 悬停底色）；标题栏钮 = WinBtn（宽 40 / 相邻贴连无间隙 / 图标 16 / text-primary / 关闭钮 hover 红底白 × / 贴角键右上圆角 8）；「文件 / 隧道」= 滑动分段（SegGroup 口径：选中段只换色不加粗）；菜单项 = SftpMenuItem（行高 26 / 图标 13 落 x=8 的 18px 槽 / 文字 x=30 起 / 13px）
  • 滚动条自己接管指针：竖条 14px / 横条 9px整条热区吃掉鼠标事件（ns-resize / ew-resize），按下即跳（拇指中心对齐按点）、拖动绝对定位 —— 文件行落在条上的那部分不再触发行的拖拽下载（实机 PanelScroll 同款：sb-ta 覆盖整条 14px）
