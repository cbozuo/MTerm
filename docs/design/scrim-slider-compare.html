遮罩浓度 · 交互方案对比

三个变体都保留「滑动条」的自由度（可拖任意值），差别只在 「档位」怎么被看见。 共同基线：与三根透明度滑杆同款（accent 已选段 + 圆心）；档位值：淡 25% / 标准 45% / 浓 65%。 拖动试玩，挑一个顺手的。

变体 1 · 三色分段轨道空间即档位

轨道自身按三档深浅分色——拖得越右、底色越浓，"松/紧"的空间感一目了然；无吸附，完全自由。 右端按所在区间显示档名。
优点：档位感最强、一眼看懂"左淡右浓"；无吸附干扰。 缺点：三段色在亮色主题下区分度会减弱；区间边界是"隐形"的（到 35% 才换档名，临界处略模糊）。

变体 2 · 节点 + 档名标签看得见的档位

三个档位做成轨道上的实心节点，节点下方直接写出「淡 / 标准 / 浓」；拖动接近节点时轻微吸附（±5%）， 当前所在档的节点与标签高亮为强调色。
优点：档位"有名有实"、可预期；吸附看得见（不会莫名其妙）。 缺点：多占一行标签高度；比另两个方案"重"一点。

变体 3 · 纯滑杆 + 拖动浮泡最干净

静态时与透明度滑杆完全一样、毫无多余装饰；只有拖动时圆心上方浮出一个小气泡显示档名/百分比，松手淡出。 （iOS 风格）
优点：四根滑杆视觉完全统一、最干净；档位信息"用时出现、不用消失"。 缺点：静态时不知道有档位（只能从右端档名推断）。
