高保真 · 2026-10-20

把「输出高亮」从两个开关升级成一套规则

现状：设置 → 终端 → 输出高亮只有「开 / 预设（标准·DevOps）/ 6 条自定义规则」，规则只有关键词或正则 + 6 档语义色，改一条要来回切页面。本稿照 iShellPro 的结构重做：预设规则可逐条开关、自定义规则可命名和任意取色，全部收在一个弹框里，改完即时生效。

① 预设规则可开关19~20 条内置规则（日期 / 级别 / 网络 / 路径…），逐条开关，不再只有「标准 / DevOps」两档打包。
② 自定义规则名称 + 正则 + 强调色同款的取色（48 色预设 + 取色盘，附对比度提示）；能删能关。
③ 两处入口、一个弹框主入口仍在「设置 → 终端 → 输出高亮」；标题栏新增「高亮」快捷入口（与「主题」并列），打开同一个弹框。

同一条日志里四类规则同时命中：日期（橙）、级别（红/加粗）、路径（紫）、IPv4（绿）、内存大小（蓝）。预设规则的颜色跟随主题 token；自定义规则是绝对色值，由 16 色预设或取色盘决定，取色时右侧实时显示它与终端底的对比度。

与现状的差异

  • 预设从「标准 / DevOps 两档」变成 逐条开关，两档合并去重后约 19 条。
  • 自定义规则从 6 档语义色（红/绿/黄/青/品红/灰）扩到 任意色：直接复用强调色那套 48 色预设 + 取色盘（同一个 ColorPickerDialog），不再单做一套色板。
  • 规则列表常驻，可删可关；顶部徽标实时显示启用数（现在要进设置页才知道开了几条）。
  • 入口两处、同一个弹框：设置 → 终端 → 输出高亮 保留为主入口；标题栏「高亮」只做快捷入口（与「主题」并列，点开即是同一个弹框）。不做终端底栏按钮 —— 底栏留给命令输入，不再塞设置类入口。

落地时的三个约束

  • 正则引擎：Rust regex 不支持 lookbehind。iShellPro 的 File Path 用了 (?<![\w.@+-])，要改写成 (^|[\s"'(=])((?:[\w.@+-]+/)+[\w.@+-]+) 并只高亮捕获组 1。
  • 任意色的载体：规则要存 RGB；渲染侧 TermSpan 的 fg/bg 本来就是颜色，不用改结构，但命中片段的 fg 要能从「ANSI 槽位」直传成 RGB。
  • 覆盖策略：默认仍然「只染程序没上色的文本」，另给每条规则一个「覆盖程序颜色」高级开关（本期可先不做）。
