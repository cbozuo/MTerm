左侧「快速连接」面板 · 组结构交互优化

面向两级组树（组头 + 成员）的交互增强稿：跨组拖拽、行内快捷操作、内联重命名、已连接徽章与搜索高亮。视觉令牌全部对齐 ui/theme.slint 与 ui/welcome.slint 现状（组头 32px / 成员 32px / 行距 2px / 组间 6px），只做交互与信息层增强，不动布局骨架。

1
跨组移动只能靠右键菜单成员行拖拽被限制在组内（#in-group-only），改组归属必须右键 → 移动到 → 选组，三步才能完成一次搬运。
2
同名会话无法区分复制链产生「202 (copy) (copy) (copy)…」，行内只有名称 + 协议图标，host 信息藏在 150ms 悬停卡里。
3
组操作发现性差重命名 / 分组颜色 / 新建分组全藏在右键菜单；组头除点击折叠外没有任何可见 affordance。
4
状态与搜索反馈弱计数徽章只有总数，看不出几个已连接；搜索命中无高亮、折叠组需手动展开、拖到折叠组毫无反馈。

DIFF与现状的差异对照

只列行为变化；布局骨架、密度、视觉令牌均保持不变。

现状优化后
跨组移动：仅组内可拖；跨组必须右键 → 移动到 → 选组成员行可直接拖入其他组：落在组成员行间 = 插入该位置；落在组头 = 加入组尾；右键菜单保留为完整入口
同名会话：行内只有名称，复制链难以区分舒适档常显副标题 user@host:port；紧凑档沿用 150ms 悬停信息卡（两档可在工具条切换）
组操作：全部藏在右键菜单组头 hover 浮现快捷操作：分组色点 / 重命名 / 更多；双击组名同样可改名
行操作：单击连接，其余全走右键行 hover 右侧浮现 ▶ 连接 / ⋯ 菜单；双击行名原地重命名
计数徽章：仅成员总数追加「已连接」小徽章（绿点 + 数字，仅 >0 时出现，常态不占信号）
折叠组：拖拽无反馈，需先手动展开拖到折叠组头悬停 0.6s 自动展开（dwell），随后可按行落点
跨组拖动中：徽章不变，看不出归属变化仅跨组时源组 -1 / 目标组 +1 实时预览（accent 底）；组内拖动徽章不变
搜索：过滤 + 自动展开，命中无高亮关键词高亮 + 命中组自动展开 + 搜索期间禁用拖拽（与现状一致）
取消拖拽：Esc / 失焦取消，ghost 飞回原位保持不变（跨组拖拽同样支持）

RULES交互规则明细

交互触发反馈提交 / 边界

跨组拖拽 · 组头ghost 悬停其他组组头组头整行组色描边 + 淡底；ghost chip 显示组名松手加入该组末尾
dwell 自动展开ghost 在折叠组头悬停 600ms该组展开，成员行入场；落点切为行间模式离开组头即取消计时；每次进入重新计时
组内重排同组成员行拖动让位动画（弹簧 90ms）+ 落点框；徽章不变松手按（命中行, 前/后）提交；越界钳制在组首/组尾
组头换序组头按下并移动 >5pxghost = 组头克隆；组间 2px accent 插入线 + 圆点松手按插入线位置换序；保留组内展开态
内联重命名双击行名 / 组名（或组头 hover 点铅笔）名称原地变为输入框，全选，accent 描边Enter / 失焦提交，Esc 取消；空名回退原值
行快捷操作hover 成员行右侧浮现 ▶（连接）/ ⋯（菜单）▶ 点亮已连接状态（绿点 + 组徽章 ●N）
组快捷操作hover 组头浮现色点 / 铅笔 / ⋯色点开 8 色板 + 无色 + 自定义；即选即生效（文件夹 / chevron / 脊线 / 落点框联动）
搜索搜索框输入按名称 / 主机过滤；命中关键词高亮；命中组自动展开；右下清除钮搜索期间禁用拖拽（可见序 ≠ 存储序）；空串恢复
