四层语义

按「点下去意味着什么」分层
① 主操作 · 唯一落点。一屏最多一个，实心强调色。
② 功能操作 · 会改状态但不落盘。强调浅填充（青绿 10%）。
②b 中性操作 · 打开 / 浏览 / 新建。中性浅填充 + 1px 边。
③ 退出 · 什么都不做地离开。无底无框，只有悬停才有面。
④ 破坏 · 只在二次确认里实心；入口用描边红（hover 才转红）。

规则：同一次操作里 ① 只能有一个；② 可以有多个；③ 永远放在 ① 的左边或最右的关闭位； ④ 必须与 ③「取消」成对出现。

04

交互：六条规则，全部可写进 Slint

每一条都对应一个真实缺陷，不是审美偏好。右上角「慢放 ×8」可以把这些时长放大到肉眼可分解。

状态机

rest → hover → active → release
悬停入场
100ms · 色阶上移一档
按下
60ms · 色阶下移两档 + 描边加深
松开
180ms · 回到悬停档
移出
140ms · 回到常态
焦点
120ms · 1px 强调边 + 3px 柔光外环

按下比悬停快（60 < 100），松开比按下慢（180 > 60），移出比移入慢（140 > 100）—— 这三组不等式就是「跟手」和「丝滑」的全部来源，不需要任何位移或缩放。

1 · 焦点只在键盘上出现

鼠标点按钮不该留一个环（会像没点干净），但 Tab 必须看见自己在哪。用 focus-visible 语义，Slint 侧对应 TouchArea.has-focus + 键盘导航标志。

2 · 禁用换灰阶，不套 opacity

半透明按钮会透出底下的分区颜色，在浅色主题里尤其像「可以点只是没生效」。改成明确的 --sec 面 + --t4 字。

3 · 异步：锁宽 + 最短 400ms

「测试连接」是唯一会连服务器的按钮。点完立刻进 loading，宽度不变（否则邻居会跳），最短展示 400ms（否则一闪而过像没反应），期间禁止再次点击。

点一下看宽度是否跳动

4 · 防重复：300ms 内的第二次点击丢弃

项目里双击有 500ms 窗口（双击标题栏最大化等）。破坏性按钮复用同一套节流：第一次点击后 300ms 内的点击不派发，避免「创建」被点两次建出两条会话。

已触发 0 次

5 · 悬停 400ms 才出提示

图标按钮没有文字，必须有 tooltip。但立刻弹出会糊住整屏，延迟 400ms、移出立即消失，用 0ms 的离场。

6 · 键盘可达

Tab 顺序 = 视觉顺序；Space / Enter 触发；Esc 等价于「取消」。焦点环永不裁切（按钮外面包一层不裁的外壳，环画在外壳上）。

// 这条已经在 highlight_dialog.slint:921 用过，此处只是收编成令牌
out property <brush> btn-ink: root.dark ? root.accent-solid.darker(0.86) : #ffffff;
#ffffff0e 是 8 位 hex（末两位 alpha）。浅色主题必须换成加黑， 否则「浅填充」在白底上等于没填 —— 这是项目里 hover-tint 早就踩过的坑。

另一条边界：按钮三态在组件内直算，不要改全局 accent-hover。 那个 token 同时被列表行悬停、侧栏选中、标签页染色复用， 把 0.12 提到 0.16 会让整屏的悬停都变重。按钮的 0.16/0.18 只活在按钮里。

import { Theme } from "theme.slint";
import { Icon } from "icons.slint";

export enum BtnTone { primary, tonal, secondary, ghost, danger, danger-ghost, link }
export enum BtnSize { xs, sm, md, lg, wide }

export component Button inherits Rectangle {
    in property <string> text;
    in property <BtnTone> tone: BtnTone.secondary;
    in property <BtnSize> size: BtnSize.md;
    in property <string> glyph: "";
    in property <bool> disabled: false;
    in property <bool> busy: false;
    in property <color> tint: transparent;   // 「应用」键：底色 = 待应用的颜色
    in property <float> surface-alpha: 1.0;  // 侧栏半透明面板（#sidebar-surface-alpha）
    in property <int> dot-tick: 0;           // busy 三点用
    callback clicked();

    property <length> bh: size == BtnSize.xs ? 24px
        : size == BtnSize.sm ? 28px
        : size == BtnSize.lg ? 38px
        : size == BtnSize.wide ? 44px : 34px;
    property <length> br: bh * 0.24;
    property <length> bpad: size == BtnSize.xs ? 10px
        : size == BtnSize.sm ? 13px
        : size == BtnSize.lg ? 20px
        : size == BtnSize.wide ? 16px : 18px;
    property <bool> framed: tone != BtnTone.ghost && tone != BtnTone.link;

    // 三态色：tone 决定色相，disabled 优先
    pure function fill(hov: bool, act: bool) -> brush {
        return disabled
            ? (tone == BtnTone.primary ? Theme.bg-elevated : transparent)
            : tint != transparent ? tint
            : tone == BtnTone.primary ? (act ? Theme.accent-solid.darker(0.18)
                                       : hov ? Theme.accent-solid.brighter(0.16) : Theme.accent-solid)
            : tone == BtnTone.tonal   ? Theme.accent-solid.with-alpha(act ? 0.26 : hov ? 0.18 : 0.10)
            : tone == BtnTone.danger  ? (act ? Theme.danger.darker(0.12) : hov ? Theme.danger.brighter(0.08) : Theme.danger)
            : tone == BtnTone.danger-ghost ? (act ? Theme.danger.with-alpha(0.18) : hov ? Theme.danger.with-alpha(0.10) : transparent)
            : (act ? Theme.bg-active : hov ? Theme.bg-hover : transparent);
    }
    pure function edge(hov: bool, act: bool) -> brush {
        return !framed ? transparent
            : tone == BtnTone.primary ? (act ? Theme.accent-solid.darker(0.30)
                                       : hov ? Theme.accent-solid.brighter(0.30) : Theme.accent-solid)
            : tone == BtnTone.tonal ? (hov ? Theme.accent-solid : Theme.accent-solid.with-alpha(0.55))
            : tone == BtnTone.danger ? (hov ? Theme.danger.brighter(0.08) : Theme.danger)
            : tone == BtnTone.danger-ghost ? (hov ? Theme.danger : Theme.border-control)
            : (hov ? Theme.border-strong : Theme.border-control);
    }
    pure function ink(hov: bool) -> brush {
        return disabled ? Theme.text-muted
            : (tone == BtnTone.primary || tone == BtnTone.danger) ? Theme.btn-ink
            : (tone == BtnTone.tonal || tone == BtnTone.link) ? Theme.accent
            : tone == BtnTone.danger-ghost ? (hov ? Theme.danger : Theme.text-secondary)
            : (hov ? Theme.text-primary : Theme.text-secondary);
    }

    height: bh;
    border-radius: br;
    border-width: framed ? 1px : 0px;
    border-color: edge(touch.has-hover, touch.pressed);
    background: fill(touch.has-hover, touch.pressed).with-alpha(surface-alpha);
    // 单一 duration：Slint 的 animate 不支持按方向给不同时长（见下方说明）
    animate background, border-color {
        duration: 120ms;
        easing: cubic-bezier(0.2, 0, 0, 1);
    }

    HorizontalLayout {
        padding-left: bpad;
        padding-right: bpad;
        spacing: glyph == "" ? 0px : 7px;
        if glyph != "" : Icon {
            glyph: root.glyph;
            tint: ink(touch.has-hover);
            size: size == BtnSize.xs ? 13px : 15px;
        }
        Text {
            text: root.text;
            color: ink(touch.has-hover);
            font-size: size == BtnSize.xs ? 11.5px : (size == BtnSize.sm ? 12.5px : 13px);
            font-weight: (tone == BtnTone.primary || tone == BtnTone.danger) ? Theme.fw-strong : 400;
            horizontal-stretch: 1;
            horizontal-alignment: center;
            vertical-alignment: center;
            // 关键：busy 时用 opacity 隐藏而不是 visible:false
            // visible:false 会让 preferred-width 归零 → 按钮宽度当场塌陷
            opacity: busy ? 0.0 : 1.0;
            animate opacity { duration: 90ms; }
        }
    }

    // busy：三点脉冲。Timer 推进下标，opacity 动画错峰
    Timer {
        interval: 120ms;
        running: root.busy;
        repeated: true;
        triggered => { root.dot-tick = (root.dot-tick + 1) % 3; }
    }
    if busy : Rectangle {
        x: (parent.width - 26px) / 2;
        y: (parent.height - 4px) / 2;
        width: 26px;
        height: 4px;
        HorizontalLayout {
            spacing: 5px;
            for i in 3 : Rectangle {
                width: 4px; height: 4px; border-radius: 2px;
                background: ink(false);
                opacity: root.dot-tick == i ? 1.0 : 0.32;
                animate opacity { duration: 120ms; }
            }
        }
    }

    // 焦点环：画在按钮自己身上，外侧 3px（父级不能 clip）
    if touch.has-focus : Rectangle {
        x: -3px; y: -3px;
        width: parent.width + 6px;
        height: parent.height + 6px;
        border-radius: br + 2px;
        border-width: 3px;
        border-color: Theme.accent-solid.with-alpha(0.16);
    }

    touch := TouchArea {
        enabled: !disabled && !busy;
        mouse-cursor: default;
        clicked => { root.clicked(); }
    }
}

③ 焦点环：必须画在会裁的那一层外面

clip: true 会把子元素的 3px 外环切掉。项目的弹框卡片、命令栏多行输入都带 clip， 而输入框的聚焦语言已经踩过这个坑（外层再包一层不裁的）。按钮同款处理： 要么给 Button 加一层外壳，要么确保祖先不裁。

④ 一条必须说清的限制

Slint 的 animate 只有一个 duration，写不出 CSS 那种 「入场 100ms / 离场 140ms / 按下 60ms」。实现统一取 120ms（与项目现有 PrimaryButton 一致）。三者的差值都在 20–60ms，肉眼无法分辨； 真要分离只能上 Timer 手写补间，不值得。
